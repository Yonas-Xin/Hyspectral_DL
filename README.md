## 📖 简介

**HYSPECTRAL_DL** 是一个专为高光谱遥感影像分析设计的端到端深度学习框架，特别针对岩性分类、地物识别等地质应用场景进行优化。该框架集成了**对比学习**与**监督学习**两大范式，提供了从样本裁剪、模型训练到大幅高光谱影像预测的完整工作流。
